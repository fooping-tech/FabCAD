利用規約

適用と同意

この規約は fooping-tech が公開する FabCAD の利用条件です。利用開始時に本規約に同意し、プライバシーポリシーを確認してください。規約バージョンは 2026-10-08、施行日は2026年10月8日です。

設計と加工の安全確認

FabCAD は試験的に公開している CAD です。形状・寸法・強度・展開図・加工データ・加工結果の正確性、特定の用途への適合性を保証しません。加工・使用前に利用者自身で設計、材料、組付け、機械設定、加工条件を検証し、設備の説明書に従って安全を確認してください。

設計データ・作品の権利と商用利用

利用者が作成した設計データ・作品について、FabCAD の利用を理由に運営者へ権利が移転することはありません。利用者に帰属する権利は利用者に留まり、商用利用も可能です。第三者の著作権・商標権・意匠権・特許権等や、読み込んだデータ・フォントの利用条件は別途守ってください。FabCAD 本体と同梱ライブラリのライセンスは作品の権利とは区別されます。

保存とバックアップ

設計の自動保存は利用中のブラウザに行われます。ブラウザデータの消去、保存容量不足、端末故障、プライベートブラウジング、サービスの変更等により保存できない場合や消失する場合があります。重要な設計は Save project でファイル保存し、バックアップしてください。

禁止事項

法令や第三者の権利の侵害、サービスへの不正アクセス、運営や他者の利用を妨害する行為は禁止します。

変更・停止と責任範囲

運営者は機能の変更、公開の一時停止または終了を行う場合があります。継続提供や保存データの維持を保証しません。利用に伴う損害についての責任制限は適用法令で許される範囲に限ります。運営者の故意・重過失による損害や、消費者契約法その他の強行法規により免除・制限できない責任には、この制限を適用しません。

規約変更と問い合わせ

変更した規約はこのページで公開します。利用条件に重要な変更がある場合は規約バージョンを更新し、利用開始前に再同意を求めます。軽微な文言修正では再同意を求めない場合があります。問い合わせは下記の GitHub リポジトリから行えます。公開の場には個人情報や機密の設計データを書かないでください。
