第三者ライセンス

FabCADは第三者が権利を持つソフトウェアとフォントを利用しています。FabCAD独自のSource Availableライセンスは、これらのライブラリ・フォントの利用条件を変更しません。

CADエンジン

  • Replicad: npmメタデータとルートのLICENSEはMITです。MITライセンス本文。Replicad本体は2023年8月14日の開発者本人によるMITへの変更を確認済みです。READMEのAGPL表記は旧記述です。
  • replicad-opencascadejs: LGPL-2.1-only。ライセンス本文。
  • Open CASCADE Technology (OCCT): LGPL-2.1と特別例外。LGPL本文、特別例外、ソースコード。

配信WASMのSHA-256・OCCT 8.0.1と対応ソースの来歴（JSON）を公開しています。配布するOCCT WASMの上流ソース候補を ソース候補アーカイブ（約68 MB） と 配布WASMとのハッシュ対応表（JSON） で提供します。これは暫定的なソース候補であり、元WASMとの完全な再現ビルドの一致・LGPL §6の対応ソースと再リンク資材の充足は未検証です。LGPLの対応ソース提供計画・現時点の不足事項も確認できます。これらの資料は再ビルドの完全な一致やLGPLの法令遵守を保証するものではありません。

過去の配布WASMに対応するソース候補は、サイト更新で消えることがないように GitHub Releases にもバージョン固定で保存します。現在のWASMに対応する固定アーカイブのURLとSHA-256は、上記の ソース・マニフェスト の archiveReleaseUrl と archiveSha256 で確認できます。これは継続的な入手手段の提供であり、ソース完全性やLGPL条件を満たしたことの証明ではありません。

ネイティブビルド依存ライブラリ

OpenCascade.jsの固定ビルド入力にはFreeTypeとRapidJSONが含まれます。WASMへ最終的に組み込まれた範囲は別途検証が必要ですが、許諾表示を保守的に公開しています。

  • FreeType（FTL / GPLv2のデュアルライセンス）: FreeType License原文、使用ビルドのソース指定。
  • RapidJSON（主にMIT、部分的に第三者許諾）: ライセンス原文・第三者通知、使用ビルドのソース指定。

実際に配布するnpm本番依存のライセンス

本番依存パッケージのライセンス原文一覧とバージョン・ライセンスの一覧（JSON）を、ビルド時にpackage-lock.jsonとnpmパッケージの許諾ファイルから生成しています。Open CASCADEのWASMを含むライブラリでは、必要な対応ソース・再リンク手段は別途確認が必要です。
